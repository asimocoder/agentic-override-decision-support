# Disclaimer

This repository is a proof-of-concept built for portfolio demonstration purposes.

It is not production-ready and is not intended for use in live credit decisioning
or any other financial decision-making context.

System prompts and domain-specific underwriting logic are intentionally withheld
from this repository. The code as published will not produce meaningful output
without them.

No real borrower data, company data, or credit assessment documents were used
in development or testing. All test runs used synthetic or redacted data.
