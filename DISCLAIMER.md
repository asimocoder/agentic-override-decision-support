# Disclaimer

This repository is a proof-of-concept built for portfolio demonstration purposes.

It is not production-ready and is not intended for use in live credit decisioning
or any other financial decision-making context.

System prompts, domain-specific underwriting logic, the anonymisation mechanism,
and entity identification patterns are intentionally withheld from this repository.
The architecture is demonstrable, but domain-specific outputs require the withheld
components.

No real borrower data, company data, or credit assessment documents were used
in development or testing. All test runs used synthetic or redacted data.

The workflow architecture and design decisions reflected here are the author's
own independent work, and do not represent the systems, processes, or intellectual
property of any current or former employer.
